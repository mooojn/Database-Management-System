# DBMS System

## Overview
This is a **Database Management System (DBMS)** built with a **C++ backend** and a **React.js frontend**. It provides a user-friendly interface for managing and interacting with databases efficiently.

## Features
- **C++ Backend**: Handles database operations, query execution, and data storage.
- **React.js Frontend**: Provides an interactive UI for users.
- **CRUD Operations**: Create, Read, Update, and Delete records.
- **Authentication**: User login and access control.
- **Efficient Query Handling**: Optimized database queries for faster response times.

## Installation
### Prerequisites
Ensure you have the following installed:
- **C++ Compiler** (GCC, MSVC, or Clang)
- **Node.js & npm** (for React.js frontend)

### Backend Setup (C++)
1. Clone the repository:
   ```sh
   git clone https://github.com/your-repo/dbms.git
   cd /server
   ```
2. Compile and run the backend:
   ```sh
   g++ -o server main.cpp -std=c++11
   ./server
   ```

### Frontend Setup (React.js)
1. Navigate to the frontend directory:
   ```sh
   cd ../app
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the frontend:
   ```sh
   npm start
   ```

## Usage
- Access the frontend via [`http://localhost:3000/`](http://localhost:3000/)
- The backend runs on [`http://localhost:5000/`](http://localhost:5000/)
- Use the interface to interact with the database
